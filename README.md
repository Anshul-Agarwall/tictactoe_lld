# tictactoe_lld
This project implements a classic Tic Tac Toe game using Low-Level Design (LLD) principles and core Object-Oriented Programming (OOP) concepts.

The goal of this project is to demonstrate clean code structure, modular design, and scalability by applying OOP fundamentals such as encapsulation, inheritance, abstraction, and polymorphism.

🚀 Features
Two-player game logic
Dynamic board handling
Input validation and win/draw detection
Clean separation of concerns using layered design
Extensible architecture for future enhancements (e.g., AI player, UI integration)
🧠 Design Approach

The application is structured using LLD principles:

Classes for core entities like Board, Player, and Game
Encapsulation to manage state and behavior
Abstraction to hide implementation details
Polymorphism for flexible player strategies (e.g., human vs AI)
🛠️ Tech Stack
Java
OOP Principles
LLD (Low-Level Design)
📂 Project Objective

This repository serves as a hands-on demonstration of designing a simple game system with a strong focus on maintainability, readability, and scalability—commonly expected in real-world software development and technical interviews.
